Visual Resource Guidelines

You may use the MyBB branding to reference, link to, and promote the MyBB Project and software.

Visual resources may also be used in "powered by" notes when using the MyBB software.

When using official MyBB branding:

  • do use official resources available on this page
  • do maintain clear space around the logo
  • don't alter the width-height ratio of the logo
  • don't change the colors of the logo
  • don't rotate, skew, stretch, or distort the logo
  • don't rearrange or mix elements of the logo, or layer it with foreign elements
  • don't add effects like shadows or gradients
  • don't compress the logo with visible artifacts or color degradation
  • don't use the logo on backgrounds that reduce its legibility
  • don't use the symbols or any of their elements as your own branding
  • don't use the logo to imply endorsement or affiliation without permission

Name and Description

MyBB (pronounced my-BEE-BEE) is the official name of the software product. Always write it as one word with exact capitalization and letter case. Do not include historical names or terms.

When referring to the organization behind the software, use the MyBB Project.

To accurately characterize the software product, use one or a combination of the following terms:

  • community software
  • discussion board software
  • forum software
  • free and open source software
  • extensible software
  • self-hosted software

When describing MyBB in the context of forums using MyBB, do not use terms like hosted by, hosted on, service provided by, or MyBB servers that incorrectly imply an active relationship, operation, affiliation, or endorsement by the MyBB Project in relation to websites or communities that choose to use the MyBB software.

Logo Lockup

The MyBB logo lockup features the MyBB Logomark and the MyBB wordmark in the same color, combined into a single visual element.

The MyBB wordmark uses the Asap SemiBold 600 Italic font.

The primary variation uses blue #007fd0 for the stroke and text color. Alternate variations use white #ffffff and gray #393d3f.

Logomark

The MyBB Logomark is a standalone symbol consisting of stylized overlapping speech bubbles superimposed over an ellipse.
